Client inputs and shader resources
  REP/NPK/IMG/font/video files, game executables and the installed bink2w64.dll
  are not distributed. Users select their own complete client folder. All such
  input files are read-only. The player does not start or modify the game.
  The required DXBC programs embedded in the player were extracted from the
  original client's shader code for this playback implementation. Their rights
  remain with the respective rightsholders; the source manifest records origin:
  https://github.com/PhysicalWorldDo/rep-player/blob/main/assets/shaders/manifest.json
  Source and player notices do not relicense those shader binaries. Original
  FXO containers, disassembly dumps, rendered client images/videos, caches and
  user settings are not included in the source repository or runtime ZIP.
