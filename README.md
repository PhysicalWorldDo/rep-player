# 原生 REP 播放器

离线播放 DNF 客户端中的 REP 录像，支持中英搜索、逐帧查看、IMG 显示控制，以及 MOV、MP4 和 PNG 序列导出。使用 C++20、Win32 和 D3D11，声音关闭。

当前 `main` 源码已支持整个 `Replay` 目录的分层播放列表和顶部“打开 REP”文件选择，以及默认图层相机修复。这些更新暂未发布 Release，下面的 v1.0.2 下载包仍为原版本；新功能需使用当前源码构建。

## 下载与运行

从 [v1.0.2 Release](https://github.com/PhysicalWorldDo/rep-player/releases/tag/v1.0.2) 下载 `rep-player-v1.0.2-windows-x64.zip`，完整解压到可写目录，**直接双击最外层的 `rep_player.exe`**。ZIP 内容直接位于解压目录：

```text
解压目录\
├─ rep_player.exe
└─ resources\
   ├─ ffmpeg.exe
   └─ licenses\
```

运行包只包含播放器、FFmpeg 和必要的第三方许可。应用图标、名称表和着色器已嵌入 EXE，无需 `build`、`ui_design` 或启动脚本。FFmpeg 用于视频解码和素材导出，请与程序一同保留。使用及构建文档留在 GitHub，不放入用户运行包。

运行需要 Windows 10 / 11 x64、支持 D3D11 的硬件 GPU，以及用户自行准备的完整客户端。FreeType、zlib 和 C++ 运行支持已静态链接，无需另装 VC++ 运行库、Python 或编译器。

首次打开后点击顶部“选择客户端”，选择包含以下内容的**完整客户端根目录**：

```text
客户端根目录\
├─ Replay\                REP 录像，可包含多级目录
│  └─ SkillReplay\        技能录像
├─ ImagePacks2\           图像资源
├─ Fonts\                录像使用的字体
├─ Video\                录像使用的视频
└─ bink2w64.dll           使用客户端 Bink 视频时需要
```

录像、图像、字体和视频均从所选客户端读取；客户端目录由用户选择，没有固定安装路径。播放器只读取这些文件，不会启动游戏。选择后，右侧上方显示播放列表，左侧显示画面，右侧下方显示 IMG 资源。顶部可切换中文 / EN。当前源码按 `Replay` 下的实际目录逐级显示全部 REP，目录根部文件也会列出；`SkillReplay` 中已登记的技能继续显示中文名。

设置、布局和缓存会在 EXE 所在目录的 `runtime` 中生成，默认导出目录为 `exports`。这两个目录不预装用户数据。运行包可完整解压到其他位置使用，无需原来的开发目录。

## 播放与查看

| 操作 | 行为 |
| --- | --- |
| 点击任意 REP 条目整行 | 立即切换并自动播放 |
| 再点当前 REP | 从头重播 |
| 顶部“打开 REP”（当前源码） | 选择任意位置的 REP 并播放；列表内文件自动定位到对应层级 |
| 底部播放 / 暂停、停止、重播 | 控制播放；结束保留末帧 |
| 空格 | 播放 / 暂停；按住只切换一次，搜索框内仍正常输入 |
| 前帧 / 后帧 | 查看相邻记录并暂停 |
| 点击画面后按 ← / → | 前帧 / 后帧 |
| 拖动竖、横分隔线 | 调整画面、播放列表和 IMG 面板大小 |

搜索同时匹配中文技能名、英文 REP 文件名、已登记的 VP 中文别名，以及当前源码中的完整相对目录路径。切换语言保留搜索条件和当前选择，未登记名称的文件显示原名。

通过“打开 REP”选择列表外的文件时，图像、字体和视频仍使用当前选定的客户端；请先选择与该录像匹配的客户端。取消文件选择会保留当前录像。

实时播放按录像时钟选择场景，追帧时可能跳过中间记录。逐帧查看按记录顺序执行，相同时间戳的记录也能分别查看。

## IMG 显示控制

“当前画面”显示当前调用的 IMG；“全部 IMG”显示当前 REP 整段资源。取消勾选会隐藏该路径的全部帧和实例，预览与导出共用隐藏状态。

| 批量按钮 | 常见路径规则 |
| --- | --- |
| 移除背景 | `map` / `background` |
| 移除怪物 | `monster`，尽量保留 `effect` / `effects` |
| 移除人物 | `character` / `npc`，尽量保留 `effect` / `effects` |

三个按钮每次点击执行一次隐藏，作用于当前 REP 整段资源。分类是近似规则，可手动勾回任意资源，或点击“全部显示”恢复；切换 REP 会清除隐藏状态。透明清屏不会移除地图背景，导出透明效果前可先隐藏背景。

## 导出素材

选好 REP 和 IMG 显示状态后，点击底部“导出素材”。输出为整个 REP 画面，使用录像原始尺寸，无界面、无声音；可选择 30 / 60 FPS、透明底、目录和文件名。输出目录须位于程序根目录内，默认使用 `exports`。

| 格式 | 透明度 |
| --- | --- |
| MOV / ProRes 4444 | 支持 Alpha，默认格式 |
| MP4 / H.264 | 不透明 |
| PNG / RGBA 序列 | 支持 Alpha，逐帧无损图像 |

导出使用独立执行器和固定时间轴，不受预览追帧影响。采样包含末帧，输出时长可能比录像多不到两帧。同名输出会提示修改文件名，取消或失败留下的 `.partial` 文件不是完成素材。

普通 RGBA 素材无法携带客户端的加法、乘法等混合操作，在其他背景上的合成可能与原画面有差异。需要透明视频时，使用支持 ProRes 4444 Alpha 的编辑软件，或选择 PNG 序列。

## 指定录像启动

通常使用界面选择即可。也可以在解压目录的 PowerShell 中执行，按提示输入自己的客户端目录：

```powershell
$CLIENT = Read-Host '输入完整客户端根目录'
.\rep_player.exe --client $CLIENT --open (Join-Path $CLIENT 'Replay\SkillReplay\Swordman\BloodyRave.rep')
```

请把录像相对路径替换为所选客户端中实际存在的文件。

播放器根据所选客户端根目录中的 `DFO.exe` / `DNF.exe` 选择回放协议，支持已核实的 REP 1.0–1.8。自建资源目录或同时包含两个程序时，可显式指定 `--profile dfo` 或 `--profile dnf-july`；播放、IMG 检查和导出使用同一选择。

资源字符串原字节保留。DFO 默认采用代码页949，DNF默认采用系统ANSI代码页；若录像文字解码报错或显示不正确，可按录像来源添加 `--codepage 949`、`--codepage 936` 或 `--codepage 65001`。界面的中文 / EN 按钮只切换界面语言。

`dnf-july` 的原生证据来自2026-07-09构建，与当前WeGame程序并非同一映像。未知opcode66及历史48字节Movie23仍会报错并定位到命令；本版没有猜测这些结构。

## 常见问题

- **选择客户端提示目录不正确：** 选择同时包含 `Replay\SkillReplay` 和 `ImagePacks2` 的上一级目录。
- **视频解码或导出找不到 FFmpeg：** 完整解压发布包，保留 `resources\ffmpeg.exe`。
- **部分画面出现占位图或视频缺失：** 检查客户端的图像、字体和视频是否齐全；不同版本的录像与资源可能不匹配。
- **中文路径或字体：** 字体支持宽字符路径，缺少韩版字体名时使用客户端中现有的中文 Noto 字体；仍需客户端 `Fonts`。
- **导出有背景或效果不完整：** 检查 IMG 勾选、格式和透明选项，可手动勾回误隐藏的素材。
- **导出提示目录范围错误：** 使用 EXE 目录内的 `exports` 或其他子目录。
