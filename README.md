# REP 播放器

离线播放 DNF 客户端中的 REP 录像，支持声音预览、中英搜索、逐帧查看、IMG 显示控制和画布扩展，可导出 MOV、MP4 和 PNG 序列。适用于 Windows 10 / 11 x64。

## 下载与运行

从 [v1.2.3 Release](https://github.com/PhysicalWorldDo/rep-player/releases/tag/v1.2.3) 下载 `rep-player-v1.2.3-windows-x64.zip`，完整解压到可写目录，直接双击最外层的 **rep_player.exe**。

```text
解压目录/
├─ rep_player.exe
├─ WebView2Loader.dll
└─ resources/
   ├─ ffmpeg.exe
   ├─ ui/
   └─ licenses/
```

保留 `WebView2Loader.dll` 和整个 `resources` 目录。无需安装 Python、编译器或 VC++ 运行库。运行需要支持 D3D11 的显卡、[Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/#download)，以及自行准备的完整客户端。

首次打开后点击顶部“选择客户端”，选择包含 `Replay` 和 `ImagePacks2` 的客户端根目录。录像、图像、字体和视频都从该目录读取；使用字体和视频的录像还需要客户端中的 `Fonts`、`Video`，Bink 视频需要对应的 `bink2w64.dll`。播放器只读取客户端文件。

播放声音还需要同一客户端根下的 `audio.xml`、`SoundPacks` 和记录中使用的 `Music` 文件。声音资源缺失或输出设备不可用时，画面继续播放，状态栏显示诊断。

## 功能

- 按实际目录层级列出整个 `Replay` 目录下的 REP，包括根部文件、多层子目录和大写 `.REP` 扩展名。
- 可在“客户端 Replay / 自定义目录”标签间切换；自定义目录支持包含子目录、刷新和搜索，目录及当前来源重启恢复，切换列表不打断播放。
- 技能录像显示中英文名称，支持中文技能名、英文文件名、VP 名称和相对路径搜索。包含帝国骑士、女蓝拳的技能及 VP 中文名称；未登记名称的文件显示原名。
- 点击列表条目自动播放，再点当前条目从头重播；播放结束保留末帧。
- 顶部“打开 REP”可选择任意位置的录像，再次打开时沿用当前录像所在目录。列表内文件会自动展开并定位；列表外文件使用当前所选客户端的资源。
- 中文 / EN 界面切换；可拖动分隔线调整画面、列表和 IMG 面板大小。

| 操作 | 行为 |
| --- | --- |
| 播放 / 暂停、停止、重播 | 控制当前录像 |
| 空格 | 播放 / 暂停；搜索框内正常输入空格 |
| 前帧 / 后帧 | 按记录顺序查看相邻帧并暂停 |
| 主窗口非文本面板内按 ← / → | 前帧 / 后帧；搜索框保留光标移动，弹窗保留自身输入 |
| 点击进度条 | 精确定位到目标时间对应记录 |
| 拖动进度条 | 即时显示目标时间，松手后精确定位；Esc 取消 |
| 音量控件 | 控制预览声音；点击展开 0–100% 滑块和静音开关 |
| 速度 | 选择 0.25×–4× 预览速度，默认 1× |

实时播放、时间定位和前后逐帧统一采用游戏原生选帧方式：只读取经过的记录，完整执行选中的场景。逐帧按记录序号选择，相同时间戳的记录也可分别查看。

倍速同时调整画面和声音，声音音调随速度变化。暂停、定位、逐帧、重播和切换录像保留当前速度；重开程序恢复 1×。素材导出仍使用录像原始时间。

短按一次移动一条记录并暂停；长按受控连续逐帧，重建期间不积压重复键，松键停止后续自动步进。主窗口播放列表中的左右键用于逐帧，目录展开/折叠使用鼠标。

时间定位选择第一条时间戳不早于目标的记录，轨道两端分别定位第一/最后记录。同时间戳的多条记录使用逐帧区分。拖动和定位时暂停声音；原来播放则完成后继续，原来暂停则保持暂停，停止/结束状态定位到中间后先暂停。目标位置与已完成位置分开显示，新目标替换旧重建；停止、切 REP 或刷新 NPK 可取消定位。

定位只渲染目标场景，保留此前实际执行过的场景留下的持久管理器状态，不补跑被跳过记录的相机、随机特效或离屏纹理指令。因此记录和时间定位准确，但交互画面不保证与从头逐条执行的导出像素相同。拖动时只更新目标，松手后定位；画面与声音并行准备，新目标或停止会取消旧候选。实际等待还取决于时间线大小、目标场景复杂度和内嵌视频的解码依赖。定位不改变导出范围或帧率。

声音使用独立的 REP 事件时间线，包含实际记录的音效、配音、音乐和环境声。暂停同时暂停声音，逐帧静音并暂停，重播从头开始，停止和切换录像清除旧声音，播放结束保留末帧并停止声音。声音与 IMG 勾选独立；画面刷新不会重新播放历史声音。AVI/BK2 影片音轨不恢复。未记录的声音不会自动补入；资源选择和原客户端混音的边界见 [AUDIO.md](AUDIO.md)。

## IMG 显示控制

右侧“当前画面”显示当前调用的 IMG，“全部 IMG”显示整段录像的资源。取消勾选可隐藏对应素材，预览和导出共用隐藏状态。

点击 IMG 行可用黄色轮廓在预览中定位素材，同路径的当前实例一起高亮。再次点击同一行或按 Esc 清除；显隐复选框保持独立。高亮跟随播放、暂停、逐帧和窗口尺寸，切换 REP 清除，不进入素材导出。

描边依据当前源素材像素、混合方式和绘制位置，可能包含后来被遮挡或被着色器裁去的部分。仅作遮罩、着色器输入或离屏输入的资源没有独立轮廓时会显示提示；隐藏素材保持隐藏。

“移除背景”“移除怪物”“移除人物”是横向并排的开关，默认全关，名称和开/关状态分两行显示。切换立即受理当前画面更新，不需要刷新 NPK，保持记录位置和播放状态；复杂录像的画面更新仍可能需要重建。三个选择保存在 `runtime`，切换 REP 和重开程序后保留。

类别规则按常见资源路径判断，怪物/人物的 effect/effects 路径免于自动隐藏，背景规则保持原覆盖。手动勾选优先：可在类别开启时勾回单个 IMG，也可在类别关闭时手动隐藏；类别来回切换保留例外。切到不同 REP 清空手动例外，同一 REP 重播和刷新 NPK 保留。

“全部显示”关闭并保存三个开关，同时清空当前 REP 的手动例外。预览、逐帧与导出共用规则；导出开始时快照选择，运行中的导出不受后来预览调整影响。类别隐藏不改变声音；手动显示也不绕过负坐标、缺失素材或其他绘制条件。

“负坐标生效”默认关闭：IMG 帧自身的 X 或 Y 为负时不绘制该帧，同一 IMG 的正常坐标帧继续显示。开启后使用原有符号偏移绘制，链接帧按目标帧坐标判断。切换按钮刷新当前画面并保持进度和播放状态，不会扩大画布。

此选择独立于 IMG 勾选和“全部显示”，切换 REP、刷新 NPK 和重开程序后保留。预览、逐帧与导出共用规则；进行中的导出保留开始时的按钮状态。只判断 IMG 自身坐标，REP 位置、相机、字体和影片不受影响。

透明底不会自动移除地图背景；导出透明素材前，可先隐藏背景。

## NPK 补丁

顶部“启用补丁 / Enable patches”默认勾选。切换勾选后显示“待刷新 NPK 生效”，点击“刷新 NPK / Refresh NPK”才应用；等待刷新时，普通播放、重播、切换 REP、逐帧与导出仍使用当前已生效的索引。取消勾选并刷新后，跳过前置补丁扫描，沿用原 `NpkIndex.etc` 和原包路径定位。

播放器保留原资源定位方式，并加载 ImagePacks2 中按文件名排在最早 `sprite*.NPK` 之前的 NPK，例如以 `!` 或 `%` 开头的补丁。SoundPacks 使用相同规则，以最早的 `sounds*.NPK` 为官方包边界；官方前缀匹配不区分大小写。排序保留大小写，按 UTF-16 字符顺序比较；`10.npk` 排在 `2.npk` 前。同路径 IMG 或声音使用最早的前置包，未覆盖路径继续使用原索引或官方包定位。两类补丁共用顶部开关。

改名、添加、删除或替换补丁后，点击顶部“刷新 NPK / Refresh NPK”。刷新会重建图像和声音资源，释放旧图片、纹理和声音缓存，从头重新播放当前 REP，保留分类开关、当前 REP 手动例外、画布、负坐标显示和预览音量设置。普通播放、重播和切换 REP 复用已应用的补丁选择；预览、逐帧和随后开始的导出共用当前资源选择，MOV/MP4 音轨也使用当前声音补丁。加载和导出期间不能切换补丁开关或刷新。

已应用的补丁开关保存在 `runtime`，重新打开程序或选择客户端时继续使用；未刷新的选择不会保存，刷新索引失败也不会覆盖上次设置。没有有效设置时默认启用。

此功能只扫描命名分界之前的包，分界之后的补丁不参与覆盖；对应目录没有 `sprite*.NPK` 或 `sounds*.NPK` 时不加载该目录的前置补丁。补丁替换整个 IMG 或声音文件；补丁 IMG 无法读取、像素解码失败或缺少所需帧时，自动跳过该 IMG，重新读取同路径的客户端原始 IMG，不弹出补丁读取错误。补丁声音读取或解码失败时回退到同路径官方声音。同包内其他有效资源继续使用，预览、逐帧与导出使用相同资源选择。客户端文件始终只读。

## 导出素材

点击底部“导出素材”，选择格式、30 / 60 FPS、透明底、目录和文件名。输出不包含界面。导出共用画布设置；MOV 和 MP4 提供“包含音频”选项，默认开启，预览静音和音量不会改变导出的原混音音量。

| 格式 | 透明度 | 音频 |
| --- | --- | --- |
| MOV / ProRes 4444 | 支持 Alpha | PCM，48 kHz 立体声 |
| MP4 / H.264 | 不透明 | AAC，48 kHz 立体声 |
| PNG / RGBA 序列 | 支持 Alpha，逐帧无损 | 无音轨，不另附 WAV |

默认输出到程序目录中的 `exports`；其他输出目录也须位于程序目录内。同名文件不会覆盖，请使用新的文件名。采样保留末帧，输出时长可能比录像多不到两帧。取消或失败留下的 `.partial` 文件不是完成素材。

普通 RGBA 无法保存所有加法、乘法混合效果，透明素材在其他背景上的合成可能与原画面有差异。透明视频需要支持 ProRes 4444 Alpha 的编辑软件，也可使用 PNG 序列。

## 设置与缓存

客户端、语言、布局、画布、声音、分类开关和负坐标显示设置保存在程序目录的 `runtime/dnf-ui.json` 中。打开录像先完整校验文件和字典，首场景与开头实际音频缓冲准备好后一起起播；后续素材按近期使用顺序后台预取。所选场景遇到尚未就绪的资源时，音画共同暂停准备，完成后恢复；实时追赶仍只执行原生选择器选中的记录。

重播和切换 REP 按容量预算复用不可变解析、声音事件、图像、纹理、字形和 PCM；每段录像的声音播放状态及场景执行状态独立。缓存可能被逐出，再用时按需准备。刷新 NPK 或切换客户端会清空旧素材缓存。支持 `Neople Video Fil` 和 `Neople Video Stream` 视频封装；解包临时文件在停止使用、切换录像或关闭播放器时回收，避免长期积累。设置和已导出素材会保留。

### 画布扩展

顶部“画布设置”提供三种方式：原始 / 1.5× / 2× / 3× 倍数、指定宽高、四边独立留边。倍数和指定尺寸将原画面居中；四边留边决定原画面距新画布左边、上边的距离。默认原始 1×，摄像机、素材像素大小和录像坐标保持不变。扩大实际渲染范围后，落在原画面边界外的已记录 IMG 可以显示到新增区域；录像指定的局部裁剪和遮罩仍保留。

三种方式分别记住参数，只有选中方式生效。“应用”更新预览并保留弹窗，“确定”应用并关闭，“取消”丢弃尚未应用的编辑；“恢复原始”先修改草稿，再应用才生效。更改画布保持当前帧和播放 / 暂停状态。预览按窗口适配完整画布，导出使用实际画布像素尺寸。进行中的导出保留开始时的设置。

切换 REP 后继续使用所选方式。倍数和留边按新 REP 原尺寸计算；指定尺寸不足以容纳新 REP 时，实际宽高至少为其原尺寸，填写的目标值仍保留。画布越大，渲染、内存和导出成本越高。

## 指定录像启动

也可从 PowerShell 指定客户端及录像：

```powershell
$CLIENT = Read-Host '输入完整客户端根目录'
.\rep_player.exe --client $CLIENT --open (Join-Path $CLIENT 'Replay\SkillReplay\Swordman\BloodyRave.rep')
```

将录像相对路径替换为实际文件。播放器优先根据客户端的 `DNF.exe` 选择 `dnf-compatible`；没有 DNF.exe 时使用 `dfo`，即使两个 EXE 同时存在也优先 DNF。支持 REP 1.0–1.8；`--profile` 可显式覆盖自动选择，自建资源目录也可用它指定。

DNF 兼容模式仅对 REP 1.8 / minor 6 中完整、独立的 `4200000000` 字典命令进行跳过，窗口会提示“兼容播放”。该 opcode 66 的原生渲染作用尚未确认，画面可能与客户端不同。其他未知指令、非零载荷、嵌入命令及不同版本仍会报错。使用 `--profile dnf-july` 可恢复严格的 7.09 读取合同，保留对 66 的拒绝。

录像头标记为中国区（country 4）时，文字自动使用 GBK / CP936，与所选资源客户端无关。仍可按录像来源指定 `--codepage 949`、`--codepage 936` 或 `--codepage 65001`，显式设置优先。

## 常见问题

- **提示客户端目录不正确：** 选择同时包含 `Replay` 和 `ImagePacks2` 的上一级目录。
- **缺少 FFmpeg：** 完整解压发布包，保留 `resources/ffmpeg.exe`。
- **画面出现占位图、字体或视频缺失：** 确认客户端资源齐全，并与录像版本匹配。国服资源采用独立字体注册，默认使用客户端或 Windows 宋体、Noto SerifSC 和 Noto Sans SC；缺字时优先尝试该字族的回退字体。原字体已有的字形保持优先。
- **旧录像的武器或界面 IMG：** 原路径缺失时支持武器名称中的调色板编号回退；界面资源可查找同目录的 `(2x)` 版本。2x 回退保留高清像素，按一半尺寸及 IMG 偏移绘制，录像坐标保持不变。
- **没有声音或提示缺失声音：** 检查静音和音量，确认录像确实有声音记录，并使用同版本客户端的 `audio.xml`、`SoundPacks`、`Music`；影片本身的音轨不播放。
- **导出有背景或效果不完整：** 检查 IMG 勾选、透明选项和格式，可手动恢复误隐藏的素材。
- **导出提示目录范围错误：** 使用程序目录内的 `exports` 或其他子目录。
- **录像提示不支持的指令：** 部分历史或不同客户端版本的录像尚不兼容，可查看错误信息定位具体文件。
