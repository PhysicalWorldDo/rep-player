REP 播放器 1.3.1

完整解压 Windows x64 运行包后，双击 rep_player.exe。
保留 WebView2Loader.dll 和 resources；运行需要 Windows 10/11 x64、D3D11 和 Microsoft Edge WebView2 Runtime。
点击“选择客户端”，选择包含 Replay 和 ImagePacks2 的客户端根目录。

支持分层录像列表、中英技能搜索、打开指定 REP、逐帧查看、IMG 隐藏及 MOV / MP4 / PNG 导出。
可切换客户端 Replay 和自定义目录；自定义目录支持子目录、刷新与搜索，目录和来源重启恢复，切换列表不打断播放。
点击 IMG 行可在预览中用黄色轮廓定位素材，同路径的当前实例一起高亮；再点同一行或按 Esc 清除。
高亮跟随播放、暂停、逐帧和预览尺寸，切换 REP 清除；显隐复选框保持独立，高亮不进入导出。
描边用于定位源素材轮廓；仅作遮罩、着色器输入或离屏输入的资源可能没有独立轮廓，面板会提示。
主窗口所有非文本面板支持左右键逐记录并暂停；搜索框仍移动光标，弹窗保留自身输入。
短按一次一条，长按受控连续逐帧，松键停止后续自动步进。点击进度条定位，拖动只更新目标、松手后精确定位，Esc取消。
原来播放则定位完成后继续，原来暂停则保持暂停；停止/结束状态定位到中间后暂停。
定位只读取经过的记录并渲染目标场景，采用游戏原生管理器状态；新目标、停止、切REP或刷新NPK可取消旧定位。
交互跳过的记录不更新相机、随机特效或缓存纹理，因此目标记录准确，但像素不保证与从头顺序导出相同。
三分类开关横向并排，默认全关并跨REP保存；手动IMG勾选优先，开关来回保留例外。
切不同REP清手动例外，同REP重播/刷新保留；“全部显示”关三个开关并清空例外。
类别更新与预览/逐帧/导出共用规则，导出使用开始时快照；类别隐藏不改变声音。
支持 REP 已记录的音效、配音、音乐和环境声。底部可静音、调整 0–100% 预览音量，设置自动保存。
声音跟随播放、暂停、停止、重播与跳转同步；逐帧时静音并暂停。
底部“速度”可选 0.25×–4×，画面与声音一起变速，声音音调也会变化。
暂停、定位、逐帧、重播及切换录像保留速度，重开恢复 1×；导出仍使用录像原始时间。
MOV/MP4 可选择包含音频，默认开启；预览静音和音量不影响导出。PNG 不附 WAV，AVI/BK2 影片音轨不恢复。
画布可按倍数、指定宽高或四边留边扩展，预览与导出共用设置。
右侧“负坐标生效”默认关闭，IMG 帧自身 X 或 Y 为负时不绘制；开启恢复有符号偏移。
选择自动保存并用于预览、逐帧与新导出，切换 REP/刷新 NPK 后保留，不扩大画布。
同时存在 DNF.exe 和 DFO.exe 时优先使用 DNF 兼容模式。
中国区录像自动使用 GBK / CP936；国服客户端采用独立字体注册和中文缺字回退。
旧武器路径缺失时支持调色板编号回退；界面仅有 (2x) 资源时，按一半尺寸及 IMG 偏移绘制，录像坐标不变。
声音仅还原已记录且资源可用的内容，不保证与原客户端逐采样一致。
打开时先完整校验文件和字典，首场景与实际开头音频缓冲就绪后一起起播；后续素材按近期使用顺序预取。
所选场景缺少已就绪资源时音画共同暂停准备，完成后恢复；实时追赶仍跳过未选中的记录。
重播和切换录像按容量预算复用解析、声音事件、图片、纹理、字形和PCM，播放及场景执行状态独立。
刷新 NPK 或切客户端会清空旧缓存；视频和批量声音解码的本次临时文件使用后自动回收。
DNF 默认启用有限兼容模式；出现“兼容播放”提示时，部分未识别指令已跳过，画面可能与客户端不同。

NPK 补丁支持：
顶部“启用补丁”默认勾选，切换后点击“刷新 NPK”才生效；待刷新时播放、切换 REP 和导出沿用当前索引。
取消勾选并刷新后跳过前置补丁扫描，使用原索引及原包定位。已应用状态自动保存，重开恢复；未刷新选择不保存。
加载 ImagePacks2 中排在最早 sprite*.NPK 之前的前置补丁，保留原资源定位方式。
补丁名按保留大小写的 UTF-16 字符顺序比较，同路径 IMG 使用最早前置包。
改名、增删或替换补丁后点击顶部“刷新 NPK”；当前 REP 从头重播，隐藏、画布及音量设置保留。
普通播放、重播和切换 REP 复用索引，预览、逐帧与导出共用。分界之后的包不作为补丁扫描。
加载及导出期间不能切换补丁开关或刷新。
补丁 IMG 无法读取、像素解码失败或缺少所需帧时，自动跳过该 IMG，改读同路径客户端原始 IMG，不弹出补丁读取错误。
同包内其他有效 IMG 继续使用，预览、逐帧与导出的资源选择保持一致。
